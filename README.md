# RESPECT Community (مجتمع ريسبكت) — Android Native

تطبيق أندرويد أصلي بالكامل (**Kotlin + Jetpack Compose + Material 3**) لمجتمع **RESPECT (`com.respect.community`)**، يجمع بين بثوث **KICK** المباشرة، التايملاين الاجتماعي، مقاطع الكليبات، ومعرض الرسومات.

## المميزات الأساسية
1. **دليل الستريمرز والاقتراحات**: استعراض ستريمرز مجتمع ريسبكت مع روابط KICK، حالة البث المباشر، وشخصيات كل ستريمر، مع نموذج لاقتراح ستريمرز جدد.
2. **جدول البثوث والتوقعات**: جدول زمني للبثوث القادمة مع اللعبة/التصنيف والتوقعات وإدارة كاملة من لوحة الإدارة.
3. **مشغل فيديو أصلي مع اختيار الجودة (ExoPlayer)**: تشغيل بثوث HLS عبر AndroidX Media3 مع تعطيل الترجمة كلياً، تحسين الـ Buffer ومنع التقطيع، واختيار جودة حقيقي (`Auto / 1080p / 720p / 480p`) عبر `TrackSelectionOverride` ووضع ملء الشاشة.
4. **تسجيل الدخول عبر KICK OAuth2 والدردشة المباشرة**: ربط الحساب عبر Chrome Custom Tabs واستقبال الدردشة المباشرة عبر Pusher WebSocket مع إمكانية إرسال الرسائل مباشرة.
5. **التايملاين الاجتماعي**: منشورات نصية، صور (مع رفع مباشر عبر **Telegraph**)، وفيديو، إعلانات رسمية من RESPECT، وتفاعل الإعجابات مع أدوات الإشراف.
6. **غرفة السوالف العامة**: دردشة مجتمعية مخصصة للسوالف مع تطبيق الكتم الإداري.
7. **تحليل البثوث**: قسم مخصص لتحليل البثوث الجارية وتقييمها من 1 إلى 10.
8. **قسم الكليبات (نمط TikTok)**: تغذية فيديو عمودية (`VerticalPager`) بأفضل لحظات الستريمرز مع ExoPlayer بدون ترجمة.
9. **معرض الرسومات (نمط Pinterest)**: شبكة متدرجة (`LazyVerticalStaggeredGrid`) مع رفع الصور عبر **Telegraph**.
10. **إشعارات سريعة**: خدمة خلفية (`StreamMonitorService`) تفحص حالة القنوات بشكل دوري (قابل للتخصيص عبر Remote Config) وترسل إشعارات عالية الأولوية بصوت واهتزاز.
11. **بحث فوري مدمج**: بحث داخل تبويب البثوث والمجتمع (الستريمرز، المنشورات، الكليبات، والرسومات).
12. **الملف الشخصي ولوحة التحكم الإدارية**: واجهة زجاجية داكنة نظيفة بـ 3 تبويبات رئيسية (`البثوث`، `المجتمع`، `حسابي`) مع **Firebase Auth + Firestore + Remote Config** ولوحة إدارة بـ 4 أقسام (المستخدمون، الإشراف، الستريمرز، الإعدادات).

## التقنيات المستخدمة
- **اللغة والواجهة**: Kotlin + Jetpack Compose + Material 3 (RTL عربية بالكامل، تصميم Obsidian داكن `#090B10` وتأثيرات زجاجية عبر مكتبة **Haze**).
- **البنية**: MVVM + Repository مع حقن اعتماد يدوي (`AppContainer`) بدون Hilt أو Koin.
- **السحابة والوسائط**: Firebase Auth + Cloud Firestore + Remote Config + Telegraph Uploader + Retrofit + OkHttp + Media3 ExoPlayer + Coil.
- **التخزين المحلي**: Room Database + DataStore Preferences.

## بناء ملف APK عبر GitHub Actions
يحتوي المشروع على سير عمل جاهز في `.github/workflows/build.yml`:
1. إعداد JDK 17 و Android SDK و Gradle.
2. إنشاء `debug.keystore` تلقائياً إذا لم يكن موجوداً.
3. تشغيل `./gradlew assembleDebug --no-daemon`.
4. رفع ملف APK الناتج باسم `RespectCommunity-debug`.
